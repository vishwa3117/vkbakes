# VK Bakes 🍰

VK Bakes is a simple and attractive cake shop website developed using **HTML5 and CSS3**. It showcases different varieties of cakes with beautiful images and a user-friendly design.

## Features
- Attractive Home Page
- Different Cake Collections
- About Us Page
- Contact Us Page
- Simple and Responsive Design

## Technologies Used
- HTML5
- CSS3

## Project Description
VK Bakes provides a simple online platform for customers to explore delicious cakes and learn more about the cake shop through an attractive and easy-to-use website.
